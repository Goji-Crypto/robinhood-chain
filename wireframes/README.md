# Wireframes

Low-fidelity, greyscale, intentionally unstyled. Each `.html` is self-contained (open in a browser);
`png/` holds exports for quick review.

| File | Screens |
|---|---|
| `stock-deck.html` | Market list, asset drawer, corporate actions, holdings lookup, banner states |
| `hanu-v2.html` | Migration flow (lock v1, receive v2), governance notice board, bridge flow |

Interaction notes are written directly on the frames. Editable versions can be re-seeded into a
design canvas on request.
